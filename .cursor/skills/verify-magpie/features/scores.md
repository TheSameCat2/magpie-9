# Scores

SCORES is the top-10 board. The player can switch tabs and return to the menu on every launch. The status depends on who answers `/api/scores`. The default Vite launch has no board, so every tab says BOARD OFFLINE. The production site at `https://magpie.nradavies.com` shows the live board: initials and scores, or NO ENTRIES YET when that tab is empty. An unpackaged desktop shell with `MAGPIE_API_ORIGIN` unset also says BOARD OFFLINE. A packaged shell with that variable unset proxies to the production board and must not say BOARD OFFLINE while the network is up.

## Sub-features

- `scores-open` opens SCORES from the menu on the board last viewed. The first visit of a session is ALL-TIME.
- `scores-offline` shows BOARD OFFLINE for ALL-TIME, BENDS, and TODAY. That is the Vite launch, and the unpackaged desktop shell with the API origin unset.
- `scores-online` shows a resolved board for ALL-TIME, BENDS, and TODAY: a list of runs, or NO ENTRIES YET. That is the production site, and a packaged shell with the API origin unset, while the network is up.
- `scores-tabs` switches boards from the tab buttons and from the arrow keys.
- `scores-back` returns to the menu with Escape or BACK.

## How to get to it (user POV)

- Choose SCORES in the main menu.
- On the board, choose ALL-TIME, BENDS, or TODAY, or press ArrowLeft and ArrowRight.
- Press Escape or choose BACK to return.

## Gotchas

- Do not snapshot the status before `wait`. The first paint is LOADING, and treating LOADING as success hides a board that never resolves.
- `NO ENTRIES YET` is the empty-board copy when the API responds. The Vite launch and the unpackaged shell do not produce it. If either of those shows `NO ENTRIES YET` or a list of initials, an API answered and that recipe's precondition failed. On production and on a packaged shell, `NO ENTRIES YET` is a successful empty tab. Wait on `scoresReach` `online`, not on one status string: a tab with runs hides the status line, and an empty tab shows `NO ENTRIES YET`.
- The shell launches delete `MAGPIE_API_ORIGIN` in the child. Exporting it beside `launch --surface desktop` or `launch --surface packaged` does not change that child. An explicit origin is a different recipe.
- `launch --surface desktop` is `electron .`. It stays offline. `launch --surface packaged` is the electron-builder unpacked binary, where `app.isPackaged` is true. Do not treat one result as the other.
- ArrowDown also changes tabs, because the scores screen treats vertical nav as a board step. Use ArrowLeft and ArrowRight, which are the keys the hint names.
- Escape on SCORES returns to the menu. It does not open the field manual. It also does not put the board back on ALL-TIME. The next open shows the tab you left.
- Initials entry is not on this screen. It appears after a scored crash that qualifies. Submitting it needs a run token. The Vite launch and the unpackaged shell do not issue one.
